## Introduction

Wireshark is a network protocol analyzer used to capture and analyze network packets.

Wireshark 是一款网络协议分析工具，用于捕获和分析网络数据包。


By analyzing packets, we can understand how computers communicate through different protocols.

通过分析数据包，我们可以理解计算机之间如何通过不同协议进行通信。

# Experiment 01: ARP Analysis

# 实验01：ARP数据包分析


ARP (Address Resolution Protocol) is used to map IP addresses to MAC addresses.

ARP（地址解析协议）用于将 IP 地址解析为 MAC 地址。


## Purpose

## 实验目的


Understand how a computer finds the MAC address of another device in the same network.

理解计算机在局域网中如何寻找目标设备的 MAC 地址。



## Process

## 工作流程


IP Address

↓

ARP Request

↓

MAC Address

↓

Network Communication



## Command

## 使用命令


Clear ARP cache:

清除 ARP 缓存：

```bash
sudo ip neigh flush all
```


Generate network communication:

产生网络通信：

```bash
ping 10.0.2.2
```



## Result

## 实验结果


Captured packets:

抓取到的数据包：


ARP Request:

Who has 10.0.2.2?


ARP Reply:

10.0.2.2 is at MAC address.

# 实验02：ICMP数据包分析

ICMP（互联网控制报文协议）用于测试网络连通性。


## Purpose

## 实验目的

## Command

## 使用命令



## Packet Analysis

## 数据包分析

Echo Reply:

接收目标回复数据包。

# Experiment 03: TCP Three-Way Handshake

# 实验03：TCP三次握手分析


TCP establishes a reliable connection through three steps.

TCP通过三个步骤建立可靠连接。


## Process

## 握手过程


Step 1:

第一步：

SYN


Client sends a connection request.

客户端发送连接请求。



Step 2:

第二步：

SYN + ACK


Server accepts the request and responds.

服务器确认请求并回复。



Step 3:

第三步：

ACK


Client confirms the connection.

客户端确认连接。



## Result

## 实验结果


Captured TCP packets:

抓取到 TCP 数据包：


[SYN]


[SYN, ACK]


[ACK]
